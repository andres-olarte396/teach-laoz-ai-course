# 03_Entregables_y_Prompts_Cliente

Documentos listos para dejar al cliente al final de cada sesión ("modo apuntes"): sin agenda de minutos, notas de instructor ni recordatorios de pago — solo lo que el cliente necesita para reutilizar lo aprendido.

## Contenido

- `Apunte_Sesion_01.md` — Framework RCTF y prompts de copywriting.
- `Apunte_Sesion_02.md` — Custom Instructions y prompts de análisis de documentos.
- `Biblioteca_Prompts_Pharma.md` — Compilado acumulativo de todos los prompts probados, organizado por categoría.

## Convención para próximas sesiones

Al cerrar cada sesión (ver roadmap en `02_Material_de_Clase/Bitacora.md`):

1. Crear `Apunte_Sesion_0N.md` a partir del material de `02_Material_de_Clase/Sesion_0N_*.md`, quitando timing interno y notas de cobro/instructor.
2. Añadir los prompts nuevos a `Biblioteca_Prompts_Pharma.md`, en la sección que corresponda (crear una nueva sección si es un tema distinto, ej. "Inteligencia Comercial" ya reservada para Sesión 4).
