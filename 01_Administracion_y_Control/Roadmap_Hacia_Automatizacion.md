# Roadmap Hacia la Automatización del Curso

Este documento define la estrategia para estandarizar y empaquetar las lecciones aprendidas durante la ejecución sincrónica de este entrenamiento.

## Fase 1: Identificación de Patrones (Sesiones 1 - 6)

* [ ] Documentar las 5 consultas/tareas más repetitivas de marketing/ventas en Pharma.
* [ ] Construir un repositorio refinado de prompts con variables parametrizables.
* [ ] Mapear los errores más frecuentes del usuario no técnico al usar ChatGPT Plus.

## Fase 2: Empaquetamiento de Recursos (Post-Curso)

* [ ] **Custom GPT / Agente:** Crear un GPT configurado específicamente para redacción y análisis Pharma.
* [ ] **Template Kit:** Diseñar una plantilla reutilizable de Notion/Markdown con los prompts probados.

## Fase 3: Escalabilidad Asincrónica

* [ ] Estructurar temario para curso grabado o taller grupal B2B para laboratorios/empresas.
* [ ] Evaluar integración con flujos de automatización (ej. n8n/Make para procesamiento de reportes vía API).
